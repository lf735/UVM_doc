RO & WO Sharing Same Address

Models distinct read-only and write-only registers mapped to the exact same physical bus address, isolating write mirrors from read status.

Key UVM APIs: default_map add_reg RO WO

Testbench Architecture Topology

shared addr 0x10
Write -> TX Buffer, Read -> RX Buffer

24`include "reg_agent.sv"

26bit [31:0] R_reg = 32'h00FF0000;
27bit [31:0] W_reg = 32'h00CCCAA0;
28 
29 
30class dut;
31 static task rw(reg_rw rw);
32 case (rw.addr)
33 'h100:
34 if (rw.read) begin
35 rw.data = R_reg;
36 if (rw.byte_en[2]) R_reg[23:16] = 8'h00;
37 end
38 else begin
39 if (rw.byte_en[0]) W_reg[ 7: 4] = rw.data[ 7: 4];
40 if (rw.byte_en[1]) W_reg[15: 8] = rw.data[15: 8];
41 if (rw.byte_en[2]) W_reg[23:16] = rw.data[23:16];
42 end
43 endcase
44 // $write("%s\n", rw.convert2string());
45 endtask
46endclass
