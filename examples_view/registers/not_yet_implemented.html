Unimplemented / Stub Registers

Handles registers reserved in the address map that are not yet implemented in silicon, preventing testbench crashes or spurious verification failures.

Key UVM APIs: uvm_reg set_check_on_read

Test Intent & Implementation Walkthrough
Source: tb_run.sv

Unimplemented / Reserved Register Handling

Demonstrates how to model unmapped, reserved, or not-yet-implemented registers:

  • Handles access to nonexistent registers gracefully without causing simulation errors
  • Returns default bus error responses or zero payloads as expected by system specification

Testbench Architecture Topology

stub reserved_reg
Returns default / ignores writes

26class dut;
27 static bit [7:0] F1 = 0;
28 static bit [7:0] F2 = 'hA5;
29 
30 static task rw(reg_rw rw);
31 case (rw.addr)
32 'h000: // Ra
33 if (rw.read) rw.data = {8'h00, F2, 8'h00, F1};
34 else if (rw.byte_en[0]) F1 = rw.data[7:0];
35`ifdef NOT_YET_IMPLEMENTED
36 'h04: // Rb
37 if (rw.read) begin
38 rw.data = {8'h00, F2, 8'h00, F1};
39 if (rw.byte_en[0]) F1 = 0;
40 if (rw.byte_en[2]) F2 = -1;
41 end
42 else begin
43 if (rw.byte_en[0]) F1 = -1;
44 if (rw.byte_en[2]) F2 = 0;
45 end
46`endif
47 endcase
