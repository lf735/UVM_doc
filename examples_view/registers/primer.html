RAL Primer & Bus Adapter

Comprehensive introductory guide to the UVM Register Abstraction Layer: creating a register model, integrating a register adapter (reg2bus/bus2reg), and running register sequences.

Key UVM APIs: uvm_reg_block uvm_reg uvm_reg_field uvm_reg_adapter uvm_reg_predictor

Simulation Flow Stepper

Interactive Execution Progression
1High-Level Register Write
2Adapter Translation (reg2bus)
3Physical Bus Execution
4Monitor Observation & Predictor
5Mirror Update & Verification

1. High-Level Register Write

Target: user_sequence

The user sequence executes a high-level write on the RAL model (`reg_model.regA.write()`). The RAL model validates fields and updates its desired value.

Expected Log Output: UVM_INFO @ 10 ns: seq [RAL] reg_model.regA.write(status, 32'hA5A5_00FF)

Testbench Architecture Topology

uvm_reg_block reg_model
High-level RAL model
uvm_reg_adapter adapter
reg2bus / bus2reg
agent bus_agent
Drives physical APB bus

26module slave(apb_if apb,
27 input bit rst);
28 
29reg [31:0] pr_data;
30assign apb.prdata = (apb.psel && apb.penable && !apb.pwrite) ? pr_data : 'z;
31 
32typedef struct {
33 reg [63:0] SRC;
34 reg [63:0] DST;
35} socket_t;
36 
37reg [ 7:0] INDEX;
38socket_t SESSION[256];
39reg [63:0] DST[256];
40reg [31:0] TABLES[256];
41reg [31:0] DMA[1024];
42 
43always @ (posedge apb.pclk)
44 begin
45 if (rst) begin
46 INDEX <= 'h00;
47 foreach (TABLES[i]) begin
48 TABLES[i] <= 32'h0000_0000;
49 end
50 pr_data <= 32'h0;
51 end
52 else begin
53 
54 // Wait for a SETUP+READ or ENABLE+WRITE cycle
55 if (apb.psel == 1'b1 && apb.penable == apb.pwrite) begin
56 pr_data <= 32'h0;
57 if (apb.pwrite) begin
58 casex (apb.paddr)
59 16'h0020: INDEX <= apb.pwdata;
60 16'h0024: begin
61 TABLES[INDEX] <= apb.pwdata;
62 end
63 16'h1XX0: SESSION[apb.paddr[11:2]].SRC[63:32] <= apb.pwdata;
64 16'h1XX4: SESSION[apb.paddr[11:2]].SRC[32: 0] <= apb.pwdata;
65 16'h1XX8: SESSION[apb.paddr[11:2]].DST[63:32] <= apb.pwdata;
66 16'h1XXC: SESSION[apb.paddr[11:2]].DST[32: 0] <= apb.pwdata;
67 16'h2XXX: DMA[apb.paddr[11:2]] <= apb.pwdata;
68 endcase
69 end
70 else begin
71 casex (apb.paddr)
72 16'h0000: pr_data <= {4'h0, 10'h176, 8'h5A, 8'h03};
73 16'h0020: pr_data <= {24'h0000, INDEX};
74 16'h0024: pr_data <= TABLES[INDEX];
75 16'h1XX0: pr_data <= SESSION[apb.paddr[11:2]].SRC[63:32];
76 16'h1XX4: pr_data <= SESSION[apb.paddr[11:2]].SRC[32: 0];
77 16'h1XX8: pr_data <= SESSION[apb.paddr[11:2]].DST[63:32];
78 16'h1XXC: pr_data <= SESSION[apb.paddr[11:2]].DST[32: 0];
79 16'h2XXX: pr_data <= DMA[apb.paddr[11:2]];
80 endcase
81 end
82 end
83 end
84end

86endmodule

215`ifdef INCA
