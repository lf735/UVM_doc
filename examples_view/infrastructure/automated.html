Automated Configuration Tables

Uses UVM field automation macros (`uvm_field_int`, etc.) and automated configuration tables for zero-boilerplate field population during build_phase.

Key UVM APIs: uvm_field_int uvm_config_db apply_config_settings

35module top;

39 my_env topenv;
40 
41 initial begin
42 //set configuration prior to creating the environment
