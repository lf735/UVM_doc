Virtual Interface Connection

Demonstrates encapsulating physical SystemVerilog interface instances in uvm_config_db and retrieving them inside UVM drivers/monitors as virtual interfaces.

Key UVM APIs: uvm_resource_db uvm_config_db uvm_component uvm_driver

uvm_exmples/mechanism/interfaces

This example will illustrate how to create a pin interface and mod port interfaces for a simple dut.

Connect a component "driver" to the pin interfaces, then to the dut.

128 super.new(name, parent);
129 d = new("driver", this);
