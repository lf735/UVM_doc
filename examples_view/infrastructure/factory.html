Factory Overrides

Demonstrates factory registration (`uvm_component_utils`), polymorphism, and swapping components dynamically using set_type_override_by_type and set_inst_override_by_type.

Key UVM APIs: uvm_factory set_type_override_by_type set_inst_override_by_type create

Test Intent & Implementation Walkthrough
Source: env_pkg.sv

Use the macro in a class to implement factory registration along with other utilities (create, get_type_name). For only factory registration, use the macro `uvm_component_registry(env,"env").

21package packet_pkg;

25 class packet extends uvm_object;
26 rand int addr;
27 rand int data;
28 
29 //Use the macro in a class to implement factory registration along with other
30 //utilities (create, get_type_name). For only factory registration, use
31 //the macro `uvm_object_registry(packet,"packet").
32 `uvm_object_utils(packet)
33
34 //Base constraints
35 constraint c1 { addr inside { ['h0:'h40], ['h100:'h200], ['h1000: 'h1fff], ['h4000: 'h4fff] }; }
36 constraint c2 { (addr <= 'h40) -> (data inside { [10:20] } ); }
37 constraint c3 { (addr >= 'h100 && addr <= 'h200) -> (data inside { [100:200] } ); }
38 constraint c4 { (addr >= 'h1000 && addr <= 'h1fff) -> (data inside { [300:400] } ); }
39 constraint c5 { (addr >= 'h4000 && addr <= 'h4fff) -> (data inside { [600:800] } ); }
40 
41 //do printing, comparing, etc. These functions can also be automated inside
42 //the `uvm_object_utils_begin/end macros if desired. Below show the manual
43 //approach.
44 function void do_print(uvm_printer printer);
45 printer.print_field("addr", addr, $bits(addr));
46 printer.print_field("data", data, $bits(data));
47 endfunction
48 function bit do_compare(uvm_object rhs, uvm_comparer comparer);
49 packet rhs_;
50 if(rhs==null || !$cast(rhs_, rhs)) return 0;
51 do_compare = 1;
52 do_compare &= comparer.compare_field("addr", addr, rhs_.addr, $bits(addr));
53 do_compare &= comparer.compare_field("data", data, rhs_.data, $bits(data));
54 endfunction
55 function void do_copy(uvm_object rhs);
56 packet rhs_;
57 if(rhs==null || !$cast(rhs_, rhs)) return;
58 addr = rhs_.addr;
59 data = rhs_.data;
60 endfunction
