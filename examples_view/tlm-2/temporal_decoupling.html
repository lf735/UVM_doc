Temporal Decoupling & Quantum Keeper

Accelerates simulation speed by letting initiators run ahead of simulation time within a defined time quantum before synchronizing with global simulation time.

Key UVM APIs: uvm_tlm_time uvm_tlm_b_initiator_socket uvm_tlm_b_target_socket b_transport

Source Specification & Design Notes

Test Intent & Implementation Walkthrough
Source: initiator.sv

TLM-2.0 Temporal Decoupling

Demonstrates time quantum and temporal decoupling using the TLM-2.0 interface:

  • Initiator runs ahead of simulation time using local time offsets
  • Synchronizes with global simulation time only upon exceeding quantum boundaries
  • Dramatically accelerates transaction-level system performance

Testbench Architecture Topology

quantum_keeper fast_initiator
Accumulates local delay
target target
Synchronizes at quantum boundaries

39 //
40 // Execute a simple read-modify-write
41 //
42 virtual task run_phase(uvm_phase phase);
43 apb_rw rw;
44 uvm_tlm_time delay = new;
45 
46 phase.raise_objection(this);
47 
48 rw = apb_rw::type_id::create("rw",,get_full_name());
49 rw.kind = apb_rw::READ;
50 rw.addr = 32'h0000_FF00;
51
52 delay.reset();
53 sock.b_transport(rw, delay);
54 $write("Init: delay = %0.3f ns\n", delay.get_realtime(1ns));
55 #(delay.get_realtime(1ns));
56 
57 // Ok to reuse the same RW instance
58 rw.kind = apb_rw::WRITE;
59 rw.data = ~rw.data;
60 
61 delay.reset();
62 sock.b_transport(rw, delay);
63 $write("Init: delay = %0.3f ns\n", delay.get_realtime(1ns));
64 #(delay.get_realtime(1ns));
65 
66 phase.drop_objection(this);
67 endtask

28class target extends uvm_component;
29 
30 local bit [31:0] m_data;
31
32 uvm_tlm_b_target_socket #(target, apb_rw) sock;
33 
34 `uvm_component_utils(target)
35
36 function new(string name = "target", uvm_component parent = null);
37 super.new(name, parent);
38 sock = new("sock", this);
39 
40 m_data = 32'hDEADBEEF;
41 endfunction
42 
43 task b_transport(apb_rw rw, uvm_tlm_time delay);
44 
45 case (rw.addr)
46 
47 32'h0000_FF00: begin
48 if (rw.kind == apb_rw::READ) rw.data = m_data;
49 else m_data = rw.data;
50 end
51 
52 endcase
53 
54 delay.incr(10ns, 1ns);
55 $write("Trgt: delay = %0.3f ps...\n", delay.get_realtime(1ns));
56 endtask
57 
58 function void start_of_simulation_phase(uvm_phase phase);
59 `uvm_info("TRGT/RPT/START", $sformatf("m_data: 'h%h", m_data), UVM_NONE)
60 endfunction
61
62 function void report_phase(uvm_phase phase);
63 `uvm_info("TRGT/RPT/FINAL", $sformatf("m_data: 'h%h", m_data), UVM_NONE)
