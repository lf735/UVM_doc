Event Synchronization (Pool)

Coordinates asynchronous parallel components using the global uvm_event_pool singleton, triggering named events and waiting on triggers across disparate components.

Key UVM APIs: uvm_event uvm_pool trigger wait_trigger

Source Specification & Design Notes

Test Intent & Implementation Walkthrough
Source: test.sv

'ep' event poll

This test is a simple test that will cover the creation of two uvm_events using the uvm_event_pool. Then use the uvm_event_pool methods to print those objects.

For a full documentation of the uvm_event and uvm_event_pool, check the files:

  • uvm/src/base/uvm_event.svh
  • uvm/src/base/uvm_event.sv
