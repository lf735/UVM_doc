Phased Execution Lifecycle

Exercises the complete 12-phase UVM execution lifecycle from build_phase to report_phase, contrasting top-down, bottom-up and runtime task phases.

Key UVM APIs: uvm_phase build_phase connect_phase run_phase report_phase

Simulation Flow Stepper

Interactive Execution Progression
1Build Phase (Top-Down Construction)
2Connect Phase (Bottom-Up Wiring)
3Elaboration & Topology Printing
4Run Phase (Time Consuming Simulation)
5Cleanup & Report Phase

1. Build Phase (Top-Down Construction)

Target: test & env

Execution begins in top-down order. The root instantiates tests and sub-components. Components query `uvm_config_db` to retrieve configuration tables and virtual interfaces before creating children.

Expected Log Output: UVM_INFO @ 0 ns: reporter [PH_TRACE] In build_phase

Testbench Architecture Topology

uvm_test test
