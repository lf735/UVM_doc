Phase Objections & Drain Time

Controls simulation duration using phase.raise_objection() and phase.drop_objection() with configurable phase drain times to allow in-flight DUT packets to flush.

Key UVM APIs: raise_objection drop_objection set_drain_time uvm_objection

Simulation Flow Stepper

Interactive Execution Progression
1Test Starts (Objections = 0)
2Raise Objection (Lock Simulation)
3Stimulus Execution
4Drop Objection
5Drain Time & Phase Termination

1. Test Starts (Objections = 0)

Target: simple_test

When `run_phase` begins, the global objection count for the phase is 0. If no component raises an objection during this delta cycle, the phase immediately ends.

Expected Log Output: UVM_INFO @ 0 ns: reporter [RNTST] Running test...

26 // This simple example shows how the uvm_test_done objection is
27 // used to coordinate end of test activity. For an example of
28 // using end of test coordination in the context of a full

31 // In this example, a drain time of 10 is set on the component.
32 // The component then forks 4 processes which consume different
33 // amounts of time. When the last process is done (time 50),
34 // the drain time takes effect. The test is completed at time
35 // 60.
36 
37 // The example also shows usage of the component objection
38 // callbacks. In this case, the dropped callback is used, but
39 // the raised and all_dropped work similarly (except the
40 // all dropped is a time-consuming task).
41 
42 import uvm_pkg::*;
43 `include "uvm_macros.svh"
44 
45 class simple_test extends uvm_test;
46 function new (string name, uvm_component parent);
47 super.new(name, parent);
48 endfunction : new
49 
50 // Register with the factory.
51 `uvm_component_utils(simple_test)
52 
53 virtual task run_phase(uvm_phase phase);
54 // Set a drain time on the objection if needed
55 uvm_report_info("drain", "Setting drain time of 10", UVM_NONE);
56 uvm_test_done.set_drain_time(this,10);
57 
58 // Run a bunch of processes in parallel
59 fork
60 doit(35);
61 doit(25);
62 doit(50);
63 doit(15);
64 join
65 endtask
66 
67 // A simple task that consumes some time.
68 task doit (time delay);
69 static int s_inst = 0; int inst = s_inst++;
70 
71 //Raise an objection before starting the activity
72 uvm_test_done.raise_objection(this);
73 
74 uvm_report_info("doit", $sformatf("Starting doit (%0d) with delay %0t",
75 inst, delay), UVM_NONE);
76 #delay;
77 uvm_report_info("doit", $sformatf("Ending doit (%0d)", inst), UVM_NONE);
78 
79 //Drop the objection when done
80 uvm_test_done.drop_objection(this);
81 endtask
82 
83 // Use an objection callback do something when objections are raised or
84 // dropped (or all dropped). This example prints some information on each
85 // drop.
86 virtual function void dropped (uvm_objection objection,
87 uvm_object source_obj, string description, int count);
88 uvm_report_info("dropped",
89 $sformatf("%d objection(s) dropped from %s, total count is now %0d",
90 count, source_obj.get_full_name, objection.get_objection_total(this)),
91 UVM_NONE);
92 endfunction

94 endclass : simple_test
