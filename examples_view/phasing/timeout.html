Simulation Watchdogs & Timeouts

Configures global simulation watchdog timers via uvm_root::set_timeout() to cleanly terminate runaway simulations with appropriate error diagnostics.

Key UVM APIs: set_timeout uvm_root uvm_fatal

Testbench Architecture Topology

root uvm_top
Watchdog timer set to 1000 ns

27//
28// To set time-out values:
29//
30// - For one phase:
31//
32// uvm_config_db#(time)::set(null, "global_timer.main", "timeout", 100);
33//
34// - For multiple phases:
35//
36// uvm_config_db#(time)::set(null, "global_timer.pre*", "timeout", 100);

49 task run_phase(uvm_phase phase);
