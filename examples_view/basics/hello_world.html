Hello World & TLM FIFO

Classic UVM hello world testbench demonstrating producer and consumer components connected through a uvm_tlm_fifo, with uvm_config_db configuration and table printing.

Key UVM APIs: uvm_component uvm_tlm_fifo uvm_config_db run_test uvm_table_printer

Source Specification & Design Notes

Test Intent & Implementation Walkthrough
Source: hello_world.sv

UVM Hello World Testbench

Demonstrates a complete hello world verification environment with table and tree printers:

  • Configures default table printer knobs (name_width, type_width, size_width, value_width)
  • Sets packet count parameters in uvm_config_int for two producer components
  • Instantiates a top environment containing two producers connected to a consumer
  • Starts the simulation lifecycle via run_test()

Testbench Architecture Topology

env top (uvm_component)

58 if(uvm_report_enabled(UVM_HIGH,UVM_INFO,""))
59 p.print();

26 function new(string name, uvm_component parent=null);

28 out = new("out",this);
29 void'(uvm_config_int::get(this, "", "num_packets", this.num_packets));
30 endfunction
31 
32 protected T proto = new;
33 protected int num_packets = 1;
34 protected int count = 0;
35 
36 `uvm_component_utils_begin(producer #(T))
37 `uvm_field_object(proto, UVM_ALL_ON + UVM_REFERENCE)
38 `uvm_field_int(num_packets, UVM_ALL_ON + UVM_DEC)
39 `uvm_field_int(count, UVM_ALL_ON + UVM_DEC + UVM_READONLY)
40 `uvm_component_utils_end
41 
42 task run_phase(uvm_phase phase);
43 T p;
44 string image, num;
45 
46 `uvm_info("producer", "Starting.", UVM_MEDIUM)
47 
48 for (count =0; count < num_packets; count++) begin
49 
50 $cast(p, proto.clone());
51 
52 num.itoa(count);
53 p.set_name({get_name(),"-",num});
54 
55 p.set_initiator(this);
56 
57 if (uvm_verbosity'(recording_detail)!=UVM_NONE)
58 p.enable_recording(get_tr_stream("packet_stream"));
59 
60 void'(p.randomize());

62 `uvm_info("producer", $sformatf("Sending %s",p.get_name()), UVM_MEDIUM)

22class top extends uvm_component;
23 
24 producer #(packet) p1;
25 producer #(packet) p2;
26 uvm_tlm_fifo #(packet) f;
27 consumer #(packet) c;
28 
29 `uvm_component_utils(top)
30 
31 function new (string name, uvm_component parent=null);
32 super.new(name,parent);
33 
34 p1 = new("producer1",this);
35 p2 = new("producer2",this);
36 f = new("fifo",this);
37 c = new("consumer",this);
38 
39 p1.out.connect( c.in );
40 p2.out.connect( f.blocking_put_export );
41 c.out.connect( f.get_export );
42 endfunction
43 
44 task run_phase(uvm_phase phase);
45 phase.raise_objection(this);
46 uvm_top.print_topology();
47 #1us;
48 phase.drop_objection(this);
49 endtask
