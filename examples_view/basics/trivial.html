Trivial Component

This fundamental example illustrates the absolute minimum UVM component lifecycle:

  • Defines a custom class 'my_component' derived from uvm_component
  • Implements the run_phase() task using raise_objection() and drop_objection()
  • Emits a basic UVM_INFO greeting message at simulation time 0
  • Instantiates the component top-level and invokes run_test() in the initial block
